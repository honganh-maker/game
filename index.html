MINI GAME ARCADE

웹 브라우저에서 바로 즐기는 6가지 미니 게임 라이브러리

🎲

Number Guessing

컴퓨터가 숨긴 비밀의 숫자를 최소한의 힌트와 시도로 맞춰보세요. 당신의 직감과 수리적 추론 능력을 시험합니다.
❌

Tic Tac Toe

가장 고전적이면서도 치열한 수싸움. 한 수 앞을 내다보고 격자판 위에 먼저 3개의 연속된 라인을 완성해 승리하세요.
✊

Rock Paper Scissors

단순함 속에 숨겨진 고도의 심리전! 연속 승리에 도전하여 컴퓨터를 상대로 최고 연승 기록을 경신해 보세요.
🐍

Snake Game

화면 속 먹이를 먹을 때마다 몸집이 늘어나는 뱀을 조종하세요. 벽이나 자신의 몸에 부딪히지 않고 한계에 도전합니다.
🃏

Memory Match

제한 시간 내에 흩어져 있는 카드들의 짝을 정확하게 찾아내어 매칭하세요. 당신의 순간 기억력을 극대화할 시간입니다.
⚡

Reaction Test

화면의 색상이 변하는 찰나의 순간을 포착하여 클릭하세요. 밀리초(ms) 단위로 측정되는 당신의 초감각 반응 속도를 확인합니다.
